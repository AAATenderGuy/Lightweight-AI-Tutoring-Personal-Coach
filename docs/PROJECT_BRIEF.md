## 1. 一句话

**Edu 是一个面向中小学课堂的本地化 AI 教学 Web 应用：教师建班、导入名单、布置在线测验或文件作业；AI 出题、批改、生成课堂；教师复核改分并导出学情报告。**

## 2. 项目类型

| 维度 | 说明 |
| --- | --- |
| 形态 | **Web 应用**（B/S），单进程 Python 服务同时提供 API 与前端静态资源 |
| 领域 | AI + 教育（K12 / 职教课堂），教师工具 + 学生学习闭环 |
| 技术栈 | 后端 **Python 3.10+ / FastAPI / uvicorn / httpx**；前端 **Vue 3 + Vite**（无 UI 框架、原生 CSS）；存储 **JSON 文件**（无数据库、无向量库） |
| AI 依赖 | 任意 **OpenAI 兼容** `/chat/completions` 接口（DeepSeek / OpenAI / 通义 / GLM / Ollama）；无 Key 时进入**离线演示模式** |
| 部署 | 源码 zip（Windows/macOS/Linux 双击启动）、Docker、云主机 systemd + Nginx |
| 资源 | **不需要 GPU**；最低 2 核 2G；单机即可跑一个班 |
| 代码规模 | Python 38 文件约 6.0k 行；Vue 18 文件约 4.9k 行；JS 约 0.5k 行；pytest 37 例 |
| 当前版本 | **v1.5.0** |

## 3. 已经能做什么

### 学生端

- **学号 + 密码登录**（教师导入名单后），或老师未导入名单时用邀请码加入；
- 看老师布置的**在线测验**与**文件作业**，提交 PDF / Word / PPT / 文本 / 图片；
- 向 AI 导师提问（苏格拉底引导 / 系统讲解，带资料出处，流式输出）；
- 一键生成 5–8 页可交互课堂，课堂内追问、小组讨论；
- 做随堂测验，看逐题解析、举一反三，查看知识点掌握度。

### 教师端

- 建班、邀请码、**导入教务名单**（CSV/粘贴）、重置学生密码、导出名单；
- 布置随堂测验 / 课后作业（在线作答或**文件提交**）、设截止、关闭/重开；
- **AI 初评 + 教师复核改分**，下载学生附件，AI 重批；
- 提交率、未交名单、每题错误率、知识点错误率；薄弱点一键补练；
- 导出班级成绩报告（HTML 看板）、班级 CSV、作业明细 CSV、学生个人报告；
- 全站 SSE 实时：学生交卷/进班、作业发布即时可见。

## 4. 技术特点（合作方最关心的四点）

1. **零基础设施**：没有数据库、没有 Redis、没有独立前端服务器；一个 Python 进程 + `data/` 目录即可运行，备份就是复制目录。
2. **离线可演示**：不配 API Key 也能走完整流程（本地规则生成 + 关键词判分），机房/答辩现场不怕断网；演示内容会显式标注。
3. **实时但不重**：SSE 只推"数据变了"的信号，客户端重拉；断线重连自动补偿，不需要消息队列。
4. **可审计的 AI 判分**：学生内容做围栏隔离防提示词注入；异常分数降级并标记待复核；教师改分保留原始分与修改记录。

## 5. 当前边界（诚实说明）

- 定位是**单机 / 小班 / 单教师**：多教师、多学校、公网高并发需要把 JSON 存储换成 SQLite/Postgres，把进程内事件总线换成 Redis；
- 检索是 BM25（无向量、无 rerank）；图片/扫描件不 OCR，转人工批改；
- 官方微信/SSO 未接入；学生密码来自名单导入，合规上建议后续换成一次性激活码或学校统一身份；
- 无 Docker/CI 的实际运行验证（文件已提供，见部署文档）。

| 打包方式？ | 源码 zip（含已构建前端）/ Docker 镜像 / 云主机 systemd + Nginx，三种都写在 [DEPLOYMENT.md](DEPLOYMENT.md)。 |
| 怎么演示？ | 双击 `start.bat`，浏览器打开 `http://127.0.0.1:8000`，用 `demo / demo1234` 登录教师端；学生端用教师导入的学号。 |
