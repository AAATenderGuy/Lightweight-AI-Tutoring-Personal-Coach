## 1. 背景与目标

### 1.1 背景

中小学教师的日常教学有三个高频、耗时的环节：

1. **出题**：随堂测验、课后作业要覆盖知识点与难度，重复劳动多；
2. **批改**：简答题、实验报告、文件作业批改量大，反馈慢；
3. **学情**：错题、薄弱点散落在纸面与表格里，难以形成下一步教学决策。

现有平台（学习通、雨课堂等）功能全但重，AI 能力弱、数据在校外；通用 AI 助手又缺少班级、作业、成绩这些教学结构。

### 1.2 目标

做一个**单机可运行、数据留在本校、AI 贯穿"教—练—评"**的轻量教学工具：

- 教师 5 分钟内建班、导入名单、发出一份作业；
- 学生用学号登录，在线答题或提交文件，立即得到反馈；
- 教师看到提交率、错题分布、知识点薄弱项，并能复核 AI 评分；
- 不配 API Key 也能完整演示（离线演示模式）。

### 1.3 成功标准（产品级）

| 指标 | 目标 |
| --- | --- |
| 教师从建班到发出第一份作业 | ≤ 5 分钟 |
| 学生从打开页面到进入作业 | ≤ 3 次点击 |
| 单班规模 | 50 人 |
| 教师批改一份文件作业的平均操作 | ≤ 2 分钟（含复核） |
| 断网/无 Key 时主流程可用 | 是（演示模式） |

## 2. 角色与权限

| 角色 | 认证方式 | 能做什么 | 不能做什么 |
| --- | --- | --- | --- |
| 教师 | 账号 + 密码（PBKDF2），Bearer token | 管理自己的班级/作业/学生/成绩；导入名单；复核改分；导出 | 访问其他教师的班级；查看未授权学生 |
| 学生 | 学号 + 密码（教师导入），HMAC token | 登录、查看本班任务、作答/提交文件、看自己的结果 | 查看他班/他人数据；改分；管理班级 |
| 访客 | 无 | 打开登录页、查看演示 | 任何写操作 |

权限边界：

- 教师接口全部校验 `Authorization: Bearer <token>`，数据按 `teacher_id` 过滤；
- 学生接口校验 `(student_id, token)`，且作业必须属于学生所在班级；
- 附件下载：教师按班级归属校验，学生只能下载自己的提交。

## 3. 核心流程

### 3.1 教师首次使用

```text
打开服务 → 登录（demo/demo1234 或注册）→ 新建班级
→ 导入名单（学号,姓名,密码）→ 把初始密码发给学生
→ 布置作业（在线测验 / 文件提交）→ 学生提交
→ 查看统计 → 复核改分 → 导出报告
```

### 3.2 学生使用

```text
打开「班级」页 → 学号 + 密码登录
→ 待完成列表 → 在线作答 或 提交附件
→ 立即看到 AI 初评（文件作业）/ 逐题解析（测验）
→ 老师复核后看到最终分与评语
```

### 3.3 实时链路

```text
学生登录/提交 ──▶ 服务端事件总线 ──SSE──▶ 教师端（概览/详情自动刷新 + toast）
教师布置/关闭作业 ──SSE──▶ 学生端（任务列表自动刷新 + toast）
```

## 4. 功能需求

> 优先级：**M** 必须有（已实现）、**S** 应该有、**C** 可以有（规划）。
> 验收标准均可通过 `pytest`、`scripts/*_smoke.py` 或手工步骤复现。

### 4.1 账号与身份

| ID | 需求 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| FR-01 | 教师注册 / 登录 / 退出 / 改密 | M | 错误密码返回 400；token 重启后仍有效；退出后旧 token 失效 |
| FR-02 | 教师会话持久化 | M | 重启服务后 `/teacher/me` 仍 200；磁盘只存 token 哈希 |
| FR-03 | 学生学号 + 密码登录 | M | 正确凭据返回 `student/klass/tasks/token`；错误返回 400 |
| FR-04 | 同号多班消歧 | M | 未填邀请码且多班匹配时返回 400 并提示；填邀请码后成功 |
| FR-05 | 学生令牌校验 | M | 无 token/错 token 访问学生接口返回 401 |
| FR-06 | 邀请码加入（兼容） | S | 未导入名单的班可用；导入后自动关闭并提示学号登录 |

### 4.2 班级与名单

| ID | 需求 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| FR-07 | 建班 / 改名 / 归档 / 删除 | M | 删除班级连带作业、学生、提交、附件 |
| FR-08 | 6 位邀请码 + 重置 | M | 排除易混字符；重置后旧码失效 |
| FR-09 | 导入名单（CSV / TXT / 粘贴） | M | 支持逗号/分号/制表符、UTF-8/GBK、表头别名；返回新增/更新/错误行 |
| FR-10 | 初始密码策略 | M | 名单无密码列时用默认密码或生成 6 位；结果只显示一次 |
| FR-11 | 重复学号处理 | M | 同班重复按最后一行；跨班同号允许，登录需邀请码 |
| FR-12 | 重置学生密码 | M | 返回新密码；旧密码立即失效 |
| FR-13 | 导出名单 | S | CSV 含学号/姓名/密码状态/最后登录，不含明文密码 |

### 4.3 资料与 AI 辅导

| ID | 需求 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| FR-14 | 上传资料（PDF/DOCX/PPTX/TXT/MD） | M | ≤10 MB；解析失败有可读提示；分块建索引 |
| FR-15 | 资料列表 / 删除 | M | 删除后检索不再命中 |
| FR-16 | AI 对话（流式） | M | SSE `meta → delta → done`；可停止；带资料出处 |
| FR-17 | 两种导师模式 | S | 引导（苏格拉底）/ 讲解；提示词不同 |
| FR-18 | 无 Key 演示模式 | M | 全流程可走通；输出显式标注"演示模式" |

### 4.4 课堂与小组

| ID | 需求 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| FR-19 | 一键生成课堂 | M | 5–10 页，含封面/讲解/讨论/检测/总结；落库可回看 |
| FR-20 | 课堂导出 PPTX | S | 讲解词进备注、答案进附录；中文文件名正常 |

### 4.5 测验与作业

| ID | 需求 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| FR-23 | 生成测验（3–8 题，难度） | M | 单选 + 简答；答案不泄漏给学生 |
| FR-24 | 交卷判分 + 逐题解析 | M | 返回分数、对错、正确答案（按 reveal）、解析 |
| FR-25 | 举一反三 | S | 按错题知识点生成同难度变式题，带详解 |
| FR-26 | 布置作业（在线 / 文件） | M | 文件模式不出题；两种模式不能互相提交 |
| FR-27 | 截止 / 关闭 / 重开 | M | 截止后学生不能提交；教师可重开 |
| FR-28 | 薄弱点补练 | S | 按错误率最高的知识点生成新作业；文件作业不支持 |
| FR-29 | 文件提交 | M | ≤20 MB；pdf/docx/pptx/txt/md/图片；重交覆盖旧文件 |
| FR-30 | AI 初评文件作业 | M | 返回分数、评语、逐条要点；无文字转人工；注入降级 |
| FR-31 | 教师复核改分 | M | 0–100 分 + 评语 + 备注；学生立即可见；保留原始分与历史 |
| FR-32 | AI 重批 | S | 可重新触发；不覆盖教师已复核分 |

## 5. 非功能需求

### 5.1 性能

| 项 | 要求 | 现状 |
| --- | --- | --- |
| 单班并发 | 50 人同时在线 | 单进程 + JSON，40 人级可用 |
| 普通接口 P95 | < 500 ms | 本地小数据满足；数据量增大需 SQLite |
| SSE 心跳 | 15 s | 已实现，断线指数退避重连 |
| 上传 | 资料 10 MB，作业 20 MB | 分块读取，超限 413 |
| 模型调用 | 超时 300 s，可取消 | 已实现；无重试 |

### 5.2 安全

| 项 | 要求 | 现状 |
| --- | --- | --- |
| 密码存储 | 加盐慢哈希 | PBKDF2-SHA256 120k（教师/学生） |
| 会话 | 可持久化、可失效 | 磁盘只存 SHA-256；12 h 过期 |
| 越权 | 教师/学生均按归属校验 | 已实现并有测试 |
| 判分注入 | 学生内容不得改变评分规则 | 围栏 + 异常降级 + 待复核 |
| 导出注入 | CSV 不以公式开头 | `= + - @` 加 `'` |
| 路径穿越 | 附件路径不得跳出 uploads | `resolve()` 校验 |
| 限流 | 防刷模型额度 | 进程内滑动窗口 |

### 5.3 合规与隐私（待补强）

- 数据默认**不出本机**，只有模型调用会把必要文本发往所配置的 API；
- 提供删除班级/学生/作业的入口；但**没有**保留期策略、审计日志、加密落盘；
- **风险**：名单导入可包含教务明文密码，K12 场景涉及未成年人信息。正式使用前建议改为一次性激活码或学校统一身份，并补充隐私说明与监护人同意流程。

### 5.4 兼容与可用性

- 浏览器：Chrome / Edge / Safari 近两年版本；移动端 390 px 起；
- 服务端：Python 3.10+；构建前端需 Node 18+；
- 无 Key 可演示；错误提示中文可读；表单有基本校验；
- 无障碍：有 `aria-label`/`role`，但弹窗无 focus trap，未系统验证。

### 5.5 可维护性

- 分层：`api/`（路由）→ `services/`（业务）→ `store.py`（存储）；
- 测试：pytest 37 例 + 4 套冒烟 + 路由一致性审计；
- 文档：README、需求、接口、部署、评审齐备；
- 债务：无 CI/lint/类型检查/结构化日志；Python 依赖未锁版本。

## 6. 数据模型（JSON 文件）

| 集合 | 关键字段 |
| --- | --- |
| `data/teachers/` | id, username, name, salt, password_hash, created_at, last_login |
| `data/sessions.json` | `sha256(token)` → {teacher_id, exp} |
| `data/classes/` | id, teacher_id, name, subject, grade, code, archived, created_at |
| `data/students/` | id, class_id, name, number, salt, password_hash, last_login, created_at |
| `data/assignments/` | id, class_id, teacher_id, title, kind, submission_mode, rubric, quiz_id, due_at, closed, reveal |
| `data/quizzes/` | id, title, topic, questions[]（单选/简答 + 答案解析） |
| `data/submissions/` | id, assignment_id, student_id, kind, score, ai, teacher_score, files[], attempts, submitted_at |
| `data/uploads/` | `<assignment>/<submission>/<file_id>.<ext>` |
| `data/lessons/` | id, title, scenes[]（cover/content/discussion/quiz/summary） |
| `data/materials/` | id, title, chunks[], preview, chars |
| `data/progress.json` | topics（掌握度）、events（最近活动） |
| `data/settings.json` | base_url, model, api_key, temperature |
| `data/secret.key` | 学生令牌 HMAC 密钥 |

约束：

- 提交 id = `sb_<assignment>_<student>`，重复提交覆盖、`attempts` 累加；
- 文件作业最终分 = 教师复核分（未复核时用 AI 初评分）；
- 班级作业不写入本机个人进度，避免多学生混在一起。

## 8. 边界与非目标

明确**不做**（当前版本）：

- 多租户 SaaS、学校/教研组层级、跨校数据汇总；
- 实时音视频课堂、白板、屏幕共享；
- 手写 OCR、图片题自动批改、语音作答；
- 移动 App / 小程序；
- 支付、订阅、发票；
- 公网级高可用（多副本、数据库集群、审计平台）。
