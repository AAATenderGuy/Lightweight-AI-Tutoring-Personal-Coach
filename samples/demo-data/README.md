## 怎么用

首次启动前，把数据铺到 `data/`：

```bash
cp -r samples/demo-data/* data/
python -m server.main
```

或者不污染 `data/`，直接把数据目录指过来：

```bash
EDU_DATA_DIR=$(pwd)/samples/demo-data python -m server.main
```

服务启动时会把 JSON 自动导入 `data/edu.sqlite3`（设 `EDU_AUTO_IMPORT=0` 可关闭）。
想重来一遍：停服务、删 `data/edu.sqlite3`、重新拷贝即可。
